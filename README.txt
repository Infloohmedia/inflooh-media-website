HOW TO USE WITH YOUR GODADDY DOMAIN
1. Create a free GitHub account at https://github.com/ if you don't already have one.
2. Create a NEW PUBLIC repository, for example: inflooh-media-website.
3. Upload index.html, styles.css and the assets folder.
4. In GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. GitHub will give you a temporary address ending in github.io.
6. In GitHub Pages, add your custom domain: www.inflooh.com.
7. In GoDaddy DNS, create the records GitHub tells you to use. Do not delete existing MX records if you use email on the domain.
8. Once DNS propagates, enable HTTPS in GitHub Pages.

IMPORTANT:
- Your domain purchase and website hosting are separate. GitHub Pages provides the hosting for this static site at no hosting cost on eligible public repositories.
- DNS changes can take time to propagate.
- The contact form is intentionally replaced by an email CTA, so there is no paid backend required.
